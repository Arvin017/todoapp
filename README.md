# Spring Boot Todo Application

A simple Todo application built while learning and revising Spring Boot.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Bootstrap
- Maven
